# FeastIT-VendorHub 

A vendor-side dashboard for managing menus, orders, profiles, and analytics for the FeastIT food delivery platform.

---

## Folder Structure
FeastIT-VendorHub/ ├── backend/ │ └── Flask-Server/ # Flask backend with APIs for vendors ├── frontend/ │ ├── public/ # Static files and assets │ ├── src/ # React components, screens, and routing │ ├── package.json # React project dependencies │ └── ... # Vite, Tailwind, config files ├── database/ │ └── feastit_schema.sql # MySQL schema and seed data ├── .gitignore ├── README.md

---

## Features

- Vendor login and session management
- Dynamic menu creation, updates, and deletions
- Real-time order tracking and status updates
- Profile management including business and security info
- Sales and performance analytics via vendor dashboards

---

## Tech Stack

**Frontend:** React, TailwindCSS, Vite  
**Backend:** Python, Flask  
**Database:** MySQL  
**Others:** Axios, React Router, Toastify
